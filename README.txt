FlipLedger V7 — Android/Desktop preview

Open index.html in Chrome on your phone or laptop, or upload index.html to GitHub Pages.
This version uses the V6.3 codebase and promotes the photo-first Scan & List flow to the home screen. Existing inventory, bulk lots, CSV import, backups, profit estimates and listing drafts remain available.

IMPORTANT LIMITATIONS:
- Camera/photo selection works in supported browsers; automatic item identification needs a configured AI backend.
- eBay sold buttons open eBay's sold-item search; individual completed sales are NOT automatically extracted or verified by this app.
- Create Listing produces an editable draft. Direct eBay publishing is NOT yet connected.
- Fee and postage values are manually entered estimates.
- Browser local storage is device/browser-specific. Export backups frequently. Data is not synced between devices.
- Do not place eBay client secrets or API keys in index.html or public GitHub repositories.

For GitHub Pages: create a repository and upload index.html at the repository root, then enable Pages from the main branch root. The optional server.py is for local testing only; it is not a secure production backend.
